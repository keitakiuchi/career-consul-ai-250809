# Manus Prompt  =========================================
# テーマ・タイトル
AI時代のキャリアコンサルティング最前線 ─ 30分でわかる「実務拡張」の可能性

# 目的
生成AIの登場でキャリアコンサルタントが実務をどう拡張できるかを具体的に紹介し、
明日からの業務に取り入れるヒントを提供する。

# 対象
・日本のキャリアコンサルタント（国家資格保有者が中心）  
・AIツール名称は知っているが具体活用はこれから学ぶ段階

# デザイン
- 基調色：ティール #008080  
- 補助色：ホワイト #FFFFFF、ライトグレー #F6F6F6、ダークグレー #444444  
- フォント：UD新ゴ（見出しはBold、本文はRegular）  
- レイアウト：フラットデザイン／余白広め／アイコン＆フラットイラスト使用  
- デモ系スライド：中央に大きめキャプチャ、左右下に要点3–4行  
- 全体トーン：専門家向けでありつつ親しみやすい。難語には（　）内で短く補足。
